# Diagnostic Exercises — Summer 2026

This repository contains my submission for the diagnostic tasks for the Summer 2026 Internship Program.

## Overview

The purpose of this repository is to demonstrate foundational setup, logic handling, data parsing, and basic Object-Oriented Programming (OOP) in Python.

### Repository Structure

- `README.md` — Setup instructions, workflow details, and reflections.
- `PROFILE.md` — Background info, technical inventory, coursework, and internship goals.
- `diagnostic/` — Contains all diagnostic source code and datasets.
  - `data/students.csv` — CSV file containing 12 student records.
  - `task1.py` — Script to process CSV data and output basic statistics.
  - `task2.py` — Text analysis function calculating word count, character count, frequencies, and longest word.
  - `task3.py` — Object-oriented implementation of `Course` and `Student` classes managing enrollment state.
